Independent REST API for the IT Support Desk system built for Activity 6.

## Requirements
- Node.js LTS and npm
- PostgreSQL database
- Postman or another API client

## Install
```bash
npm install
```

Copy `.env.example` to `.env` and set `DATABASE_URL` to your PostgreSQL connection string. Keep `.env` private and never commit it.

## Create the table and seed eight fictional records
```bash
npm run db:setup
```
The seed script inserts its sample records only when the table is empty. Run it once for a new database.

## Start
```bash
npm start
```
Open `http://localhost:3000`.

## Routes
- `GET /`
- `GET /health`
- `GET /api/records`
- `GET /api/records/:id`
- `POST /api/records`
- `PUT /api/records/:id`
- `DELETE /api/records/:id`

POST and PUT JSON body:
```json
{
  "title": "Wi-Fi connection problem",
  "category": "Network",
  "description": "The library Wi-Fi connection is unavailable.",
  "status": "Pending"
}
```
Do not send `id`. It is generated by the database.

Allowed statuses: `Pending`, `In progress`, `Completed`.

## Test with Postman
Import `postman/Activity7-API.postman_collection.json`. Set `baseUrl` to `http://localhost:3000` (or your deployed URL). Run the requests in order. The POST request saves its returned ID in the collection variable for subsequent GET, PUT and DELETE requests.

## Deploy
1. Push this project to a GitHub repository. Include `package.json` and `package-lock.json`; exclude `.env` and `node_modules`.
2. Create a PostgreSQL database with your hosting provider and copy its connection string.
3. Create a Node.js Web Service in Render connected to the backend repository.
4. Set build command to `npm install` and start command to `npm start`.
5. Add environment variables: `DATABASE_URL`, `NODE_ENV=production`, `CLIENT_ORIGINS=https://activity-6-frontend.netlify.app`, and `STUDENT_NUMBER=202510514`.
6. Run the schema and seed SQL against the hosted PostgreSQL database (or run `npm run db:setup` locally using the hosted database URL).
7. Deploy and test `/health` and every CRUD route using the live URL.

Do not put database credentials in GitHub. Render free services may sleep when idle; the first request can take time.
